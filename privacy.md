# NotchCli Privacy Policy

Effective date: August 16, 2026

NotchCli does not collect, transmit, sell, or share personal data.

## Local files

NotchCli reads Claude Code and Codex CLI log folders that you explicitly choose. Access is read-only and stored as a security-scoped bookmark in the macOS App Sandbox. Usage totals, quota samples, and incremental scan caches stay on your Mac.

## Network access

NotchCli makes no network requests. It includes no analytics, advertising, telemetry, crash-reporting, or third-party tracking SDKs.

When enabled, Claude quota is requested by running the locally installed Claude Code command-line tool. NotchCli does not read Claude Code credentials and does not contact Claude services itself.

## Data retention and deletion

NotchCli stores only local preferences, folder permissions, quota samples, and scan caches needed to show usage. You can remove these items by deleting NotchCli's application support, preferences, and cache data from your Mac.
