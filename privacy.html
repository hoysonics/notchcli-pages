NotchCli Privacy Policy

Effective August 16, 2026

NotchCli keeps your Claude Code and Codex CLI usage data on your Mac. It does not sell personal data or use data for advertising or cross-app tracking.

Local files

NotchCli reads Claude Code and Codex CLI log folders that you explicitly choose. Access is read-only and stored as a security-scoped bookmark in the macOS App Sandbox. Usage totals, quota samples, and incremental scan caches stay on your Mac.

Analytics and network access

When Share app analytics is enabled, NotchCli uses Google Firebase Analytics to send app launch and session activity, app version, operating system and device information, and approximate region derived from a masked IP address. Firebase assigns an installation identifier for this purpose. This data is used only to understand aggregate app usage and reliability.

NotchCli does not send CLI log contents, file paths, token counts, quota values, model names, account credentials, or the content of your work. Advertising identifiers and cross-app tracking are disabled. NotchCli does not include advertising or crash-reporting SDKs.

You can turn analytics off at any time in NotchCli Settings. Turning it off stops collection and resets the analytics identifier stored by the app. Analytics data already received by Google may remain in aggregated or retained records according to Google Firebase's data retention practices.

When enabled, Claude quota is requested by running the locally installed Claude Code command-line tool. NotchCli does not read Claude Code credentials and does not contact Claude services itself.

Data retention and deletion

NotchCli stores local preferences, folder permissions, quota samples, scan caches, and—while analytics is enabled—a Firebase installation identifier. You can remove local app data by deleting NotchCli's application support, preferences, and cache data from your Mac.
